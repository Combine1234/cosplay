# Closet interactive prototype

ต้นแบบ marketplace เสื้อผ้ามือสองภาษาไทยที่ทำงานในเบราว์เซอร์เครื่องเดียว ข้อมูลสินค้า บัญชีเดโม ตะกร้า ข้อเสนอ คำสั่งซื้อ และคำแนะนำผู้ขายเก็บใน IndexedDB

## เปิดใช้งาน

ต้องเปิดผ่าน local server เพราะ JavaScript แบ่งเป็น ES modules:

    npm start

แล้วเปิด http://127.0.0.1:4173

## เส้นทางเดโมแนะนำ

1. กด **เข้าสู่ระบบเดโม** และเลือก Nicha เพื่อซื้อ หรือ Mali/June เพื่อจัดการประกาศ
2. ที่ Discover ใช้ตัวกรองหรือ **AI ช่วยหา**; กด **+** บนการ์ดเพื่อเพิ่มสินค้าใน Outfit Studio
3. เลือกสินค้าแล้วกด **แมตช์ชุดนี้กับอะไรดี**; ลองชุดและเพิ่มทั้งชุดลงตะกร้า
4. เปิดสินค้าที่มีป้าย **มีตำหนิ**; เลือกรูป **Flaw / Defect** แล้วใช้ปุ่มซูม
5. ส่งข้อเสนอ จากนั้นสลับไปยังเจ้าของสินค้าใน My Closet > ข้อเสนอ เพื่อตอบ
6. สร้างคำสั่งซื้อจากตะกร้า ชำระเงินจำลอง สลับผู้ขายเพื่อจัดส่ง แล้วสลับผู้ซื้อเพื่อยืนยันรับ
7. กด **เวลาเดโม +0 วัน** เพื่อเลื่อน 15 วันและสร้างคำแนะนำประกาศ; สลับเป็นเจ้าของแล้วเปิด My Closet > คำแนะนำ

## ข้อจำกัด

- ไม่มีรหัสผ่าน การยืนยันตัวตน การรับเงินจริง ขนส่งจริง หรือการแจ้งเตือนภายนอก
- AI เป็นกฎที่อธิบายได้และใช้เฉพาะข้อมูลเดโม ไม่วิเคราะห์รูปหรือสร้างสินค้า
- ภาพเสื้อผ้าเป็นภาพประกอบ SVG ที่สร้างขึ้นสำหรับเดโม รูปผู้ใช้อัปโหลดจะเก็บต้นฉบับไว้
- Outfit Studio แสดงองค์ประกอบของลุค ไม่รับประกันความพอดี สี หรือเนื้อผ้าจริง
- ข้อมูลไม่ซิงก์ข้ามอุปกรณ์และอาจหายเมื่อล้างข้อมูลเว็บไซต์

## ทดสอบ

    npm test

ชุดทดสอบครอบคลุมกฎราคา ขอบเขต 14 วัน การจับชุด การตรวจตำหนิ ข้อเสนอ สิทธิ์ผู้ใช้ การจอง 15 นาที และความเป็นอะตอมของการซื้อหลายชิ้น
